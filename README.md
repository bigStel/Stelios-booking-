# Professional Service Landing Page with AI Assistant & Booking

![React](https://img.shields.io/badge/React-19-blue.svg)
![Tailwind](https://img.shields.io/badge/Tailwind-CSS-38B2AC.svg)
![Gemini](https://img.shields.io/badge/Google-Gemini_API-orange.svg)

Μια σύγχρονη και πλήρως responsive landing page για επαγγελματίες, η οποία περιλαμβάνει ενσωματωμένο **AI Chatbot (Gemini API)** και σύστημα κρατήσεων μέσω **Google Calendar**.

## ✨ Χαρακτηριστικά

- 🤖 **AI Assistant**: Έξυπνος ψηφιακός βοηθός που απαντά σε ερωτήσεις πελατών σε πραγματικό χρόνο.
- 📅 **Interactive Booking**: Διαδραστικό ημερολόγιο για εύκολο προγραμματισμό ραντεβού.
- 📱 **Responsive Design**: Βελτιστοποιημένο για κινητά, tablet και desktop (χρήση Tailwind CSS).
- ⚡ **No-Build Performance**: Χρήση ESM modules και Import Maps για άμεση φόρτωση χωρίς περίπλοκα build steps.
- 🎨 **Modern UI/UX**: Καθαρό design με Lucide Icons και Smooth Animations.

## 🛠️ Τεχνολογίες

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS
- **AI**: @google/genai (Gemini 2.5 Flash)
- **Icons**: Lucide React

## 🚀 Πώς να το τρέξετε

1. Κλωνοποιήστε το repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Ανοίξτε το αρχείο `index.html` στον browser σας (ή χρησιμοποιήστε ένα Live Server).
3. Βεβαιωθείτε ότι έχετε ρυθμίσει το `API_KEY` για το Google Gemini στο περιβάλλον σας.

## 🔑 Ρύθμιση AI Assistant

Το chatbot χρησιμοποιεί το μοντέλο **Gemini 2.5 Flash**. Για να λειτουργήσει, απαιτείται ένα έγκυρο API Key από το [Google AI Studio](https://aistudio.google.com/).
